إعداد قاعدة البيانات

لتفعيل أقسام وظائف سوريا الجديدة بأمان، نزّل ملف الترحيل وافحصه، ثم شغّله من Supabase Dashboard → SQL Editor على قاعدة المشروع.

تنبيه أمني: لا تعطّل Row Level Security (RLS) على جدول الإعلانات. تعطيلها يتيح الوصول غير المصرّح به إلى الطلبات وقد يسمح بتعديلها أو حذفها.
  1. شغّل ملف الترحيل migration-listing-types.sql مرة واحدة.
  2. أنشئ حساب المشرف في Supabase Authentication، ثم أضف UUID الخاص به إلى جدول admin_users كما توضح تعليمات النشر.
  3. لا تشارك مفاتيح الإدارة أو بيانات اعتماد Supabase في هذه الصفحة.
