# تفعيل النسخة الجديدة على Supabase

التغييرات البرمجية موجودة في المستودع، لكن قاعدة Supabase الحية لم تُعدّل تلقائيًا.

1. من Supabase Dashboard افتح **SQL Editor**، ثم شغّل محتوى `migration-listing-types.sql` مرة واحدة على المشروع الحالي. هذا يضيف نوع الإعلان (وظيفة/باحث)، والخبرة وطريقة العمل، ويعيد تفعيل RLS بسياسات تقصر التعديل والحذف والإدارة على المشرفين. لا تشغّل `fix-publish.sql` القديم؛ أصبح الآن ملاحظة تمنع تعطيل RLS.
2. في **Authentication → Users** أنشئ حساب بريد/كلمة مرور للمشرف. انسخ UUID الخاص به، ثم أضفه من SQL Editor: `insert into public.admin_users (user_id) values ('UUID');`.
3. افتح `admin.html` وسجّل الدخول بهذا الحساب. الحسابات غير الموجودة في `admin_users` لا تصل إلى لوحة المراجعة.
4. انشر ملفات الموقع بعد مراجعة التغييرات. لن تعمل الأقسام الجديدة ولا الإرسال قبل ترحيل قاعدة البيانات.

كل طلب «مطلوب وظيفة» يخزن كتاريخ انتهاء 60 يومًا، ويُعاد ضبط الموعد إلى 60 يومًا عند اعتماد المشرف له. وسيلة الاتصال اختيارية لكنها ستصبح عامة بعد اعتماد الإعلان إذا أضافها صاحبه.


## نموذج «تواصل معنا» وصندوق الوارد

التغييرات الجديدة تضيف واجهة تواصل ونقطة API خادمية في `api/messages.js` تحفظ الرسائل في جدول `messages`. الرسائل لا تُدرج مباشرة من المتصفح؛ تستخدم نقطة API مفتاح Supabase الخادمي المحفوظ في متغيرات بيئة Vercel، بينما يتيح RLS القراءة للمشرفين المعتمدين فقط.

1. بعد مراجعة الكود، شغّل `migration-contact-messages.sql` من **Supabase Dashboard → SQL Editor** على مشروع `syria-jobs`. هذا ينشئ الجدول ويمنع القراءة العامة.
2. في إعدادات مشروع Vercel، أضف المتغيرات التالية إلى **Production** (وإلى Preview إذا أردت اختبار النماذج على معاينات الفروع):
   - `SUPABASE_URL` — عنوان مشروع Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY` — مفتاح service role؛ احفظه في إعدادات Vercel فقط، ولا تضفه إلى Git أو المتصفح.
   - `TELEGRAM_BOT_TOKEN` — رمز البوت الذي أنشأته عبر BotFather.
   - `TELEGRAM_CHAT_ID` — معرّف المحادثة/المجموعة التي تستقبل التنبيهات.
3. أعد نشر Vercel بعد حفظ المتغيرات، ثم أرسل رسالة اختبار وتحقق من ظهورها في تبويب **صندوق الوارد** ووصول تنبيه Telegram.

إذا لم تُضبط متغيرات Telegram، ستظل الرسائل محفوظة وقابلة للعرض في لوحة الإدارة، لكن لن يصل التنبيه. فحص المستودع الحالي وجد أن `bot.py` هو جامع وظائف تجريبي ولا يحتوي على إرسال Telegram للإعلانات؛ التعديل الجديد يضيف تنبيه الرسائل الواردة فقط ولا يغيّر سلوك جامع الوظائف.
